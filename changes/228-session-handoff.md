- **Hand a session off to another provider.** When one provider hits its usage limit, or you want a second opinion or another model's strengths, choose **Hand off…** in the session's ⋯ menu or the command palette, or click another provider's tile in the session's model picker ("Continue in a new … session"). Pick the provider and model, and optionally say what to do next. The new session gets the same code as a fork (a new branch with the original's uncommitted changes) and, instead of the conversation, a brief CodeDen writes from the original's transcript: the task, later requests, where the work got to, open todos, the files edited and your note. It works on every provider, including ones that can't fork, and the original session is unchanged. The utility model writes the "where it got to" summary; switch it off in Settings > Utility model > Handoff summaries.
