- **Session details no longer shows made-up usage.** The Context window section shows only what the provider reported: a figure it hasn't reported reads "—", and the bar appears once the context size is known. The cost comes from the usage ledger, like the session header: estimates are marked "≈", subscription logins see "API-equivalent", a session with no turns says "No usage yet", and a model with no price says "Not priced". Before, any missing figure fell back to sample values, so every Codex session claimed "$1.84 this session" and a new session showed 68k of 200k tokens used.
