- **Turn a provider off.** Settings → Providers → Installed providers has a switch for each detected provider. A provider you turn off is no longer offered in the model pickers or picked by Auto, the role defaults, the software factory (builders, reviewers, the scout), a role's usage-limit fallback or the utility model, so an installed CLI you don't use (or have no licence for) can't stall work. Sessions already on it keep working, and turning it back on takes effect at once.
