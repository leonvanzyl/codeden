- **Agents can click, hover, drag and scroll at screenshot coordinates in the session browser.** The new `browser_mouse` tool acts at a point the agent reads off a browser screenshot, so agents can work with things that have no element to pick: canvases, maps, charts, drag handles, custom sliders, games and hover menus. It supports double and right clicks and held keys such as Shift. It works for every provider and on both browsers, the streamed one and the desktop app's native one, and the **Agent is acting** chip shows while it runs. `browser_type` without an element now types into whatever has focus, for example a canvas editor the agent just clicked into.
