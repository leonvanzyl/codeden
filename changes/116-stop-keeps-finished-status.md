- **A finished session keeps its status.** The session header's ⋯ menu offers **Stop session** only while the agent is working or waiting on you, as the sidebar's session menu already did. A Done session can no longer be turned into Stopped by a stray click. Stopping a session that already completed or failed (from the menu, the PM or the API) still ends its agent process, but its status stays Done or Failed in the sidebar, the project's session list and the PM's digest.
