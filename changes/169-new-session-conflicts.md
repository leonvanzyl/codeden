- **The "Already running" card in New session follows your draft.** Before, Wait, Join and Force started the message as it was when you first sent it, so text, options and images you changed afterwards were lost. Now they start the draft as it is when you click, and the card names that message. While the composer is empty, they wait for a task; Skip still works. Sending the draft again checks the new version and replaces the earlier conflict, so the inbox keeps one item per request instead of a stale copy for every send.
- **Pasted images in a conflicting start are saved as files.** A start that matched running work used to copy pasted screenshots into the event log as text, once per send. They are now saved as artifacts first, as queued messages already were, and so is a start waiting behind other work after Wait.
