- **Claude Code 2.1.290 or newer is now the minimum.** Claude's current models refuse older versions ("does not support this model; version 2.1.290 or newer is required"), so setup now flags an older `claude` and offers `claude update`. CodeDen's Claude support moves to Claude Agent SDK 0.3.330, which CodeDen installs on its own the next time a Claude session starts.
