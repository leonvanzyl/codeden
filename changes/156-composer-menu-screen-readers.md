- **Screen readers announce the composer's `/` and `@` menus.** Typing `/` or `@` in a session's message box opened a list of commands and skills or files, but a screen reader didn't say so: not that a list opened, not which entry was highlighted as you pressed the arrow keys, and not what Enter would insert. The message box now tells a screen reader when the list opens and closes and which entry is highlighted. The list is named **Commands & skills** or **Files**, each entry says what it is ("/release, command", "src, folder") along with its description, and as you type it announces how many entries match what you typed ("2 results for /re"), or "No matches". Nothing changes for mouse, touch or keyboard use.
