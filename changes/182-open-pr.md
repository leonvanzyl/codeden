- **Open PR from the session's Diff panel.** In a GitHub project, the git bar has an **Open PR** button that asks the agent to open a pull request for the session's work. The agent commits what's left, pushes and writes the description. The request is queued behind a running turn. A successful push offers the same next step, and the Issue / PR tab offers it while nothing is linked. Once the PR is open, the git bar shows **PR #N** and opens it. The button appears in sessions you started on their own branch; sessions a PM, automation or the factory started still open their own PRs.
