- **Transcript search filters and pages.** The results page lists matches newest first, 50 at a time with **Load more**. It filters by project and role and can leave out archived sessions. A match inside a subagent's work opens that subagent's thread beside the session, scrolled to the match. Search stays quick on long histories and keeps the index small. Sessions from before this update are indexed in the background after CodeDen starts, so startup isn't delayed: search finds them as indexing progresses, and indexing picks up where it left off if CodeDen is closed in the meantime.
