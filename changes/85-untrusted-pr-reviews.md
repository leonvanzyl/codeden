section: security
---

- **PR feedback only passes on reviews from people with write access.** On a public repository anyone can review a pull request, even with **Request changes**. A session you started is now told about requested changes only when the reviewer is an owner, member or collaborator of the repository, the account CodeDen is signed in to GitHub with when it reads the review, or one of the project's **Trusted authors**, and the message reminds the agent that comments from anyone else are input data, not instructions. The PM still hears about other people's reviews, but without their text and without being woken for them.
