- **Memory files, skills and subagents can be edited on a phone.** On the Agents page's Memory, Skills and Subagents tabs, a phone showed the file list beside the editor, which left the editor a strip a few dozen pixels wide: the text wrapped a letter per line and Revert, Delete and **Review & save** were cut off. A phone now shows the list at full width, and tapping a file opens it in the list's place with a **Back** button. The toolbar wraps onto two rows so the whole path and every button fit, with 40 px buttons. Going back keeps unsaved changes, so you can open the same file again and carry on. The tabs scroll sideways instead of wrapping, and skill switches are easier to tap on touch screens. Tablets and desktops keep the list beside the editor.
