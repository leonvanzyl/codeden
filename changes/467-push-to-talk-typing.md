- **Push-to-talk no longer takes over a key you type with.** The shortcut recorder in Settings → Voice used to save a key on its own, such as Space or a letter. That key then started dictation, and never got typed, in the composer and every other text field. The recorder now asks for Ctrl/Cmd or Alt with the key (a function key such as F8 works on its own). A key saved earlier without one types normally in text fields and only starts dictation elsewhere. Typing the push-to-talk key while dictating from the microphone button also no longer stops the dictation.
