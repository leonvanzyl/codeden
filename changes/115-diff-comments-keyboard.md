- **Diff review comments can be started from the keyboard.** Each file in the Diff panel now has a **Comment** button that Tab reaches and screen readers announce with the file's name. It opens a list of the file's diff lines, removed lines included. Arrow keys pick a line, Shift with the arrows picks several, **Enter** opens the comment editor under them with the caret in it, and **Esc** closes the list. Before, a comment could only be started by hovering a line with the mouse or tapping it. The mouse and touch **+** still work as before.
